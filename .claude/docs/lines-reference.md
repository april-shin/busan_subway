## 노선별 특이사항

- 신분당선은 `'SB'`와 `'신분당'` 두 가지 ID가 모두 색상/이름 맵에 등록되어 있다. `lines.json`에서는 `'SB'`를 사용한다.
- **5호선 마천 지선(550 둔촌동 ~ 556 마천)은 539(강동)에서 분기한다.** 역 목록이 하남 방면
  종점 549(하남검단산) 다음에 둔촌동을 나열하므로 `generate_station_data.dart` 의 자동 인접
  연결이 `549 → 550` 이라는 없는 연결을 만든다. 생성기의 `lineId == '5'` 블록이 이를 제거하고
  `539 → 550` 을 추가한다. 이 처리가 빠지면 5호선이 지선 없는 일직선이 되어 (1) 천호→마천이
  하남검단산을 돌아가는 19역 경로로 뽑히고 (2) 지도 실시간 열차의 지선 판정이 무력화돼
  `천호 → 굽은다리` 경로에 마천행이 표시된다. 회귀 가드: `test/data/line5_macheon_branch_test.dart`.
- 경의중앙선 서울역 지선은 **K20(가좌)에서 분기**하는 dead-end `가좌 – 신촌(경의중앙선, K57) – 서울역(K54)` 이다
  (2026-10-16 교정 — 종전엔 K24(효창공원앞)에 잘못 붙어 있었다). K57 은 2호선 신촌(240)과 **환승이 아닌 별개 역**이고
  역명은 도착 API 등록명 `신촌(경의중앙선)` 그대로여야 한다(치환 맵에 넣지 말 것). 번호가 물리 순서와 어긋나
  `line_direction.dart` 에 K57/K54 rank 가 있다. 회귀 가드: `test/data/gyeongui_seoul_branch_test.dart`.
  K55(임진강)·K56(운천)은 K01(문산) 이북 연장 구간으로 하루 2~4편만 운행한다.
- **경강선(`'경강'`, GG01 판교 ~ GG12 여주)은 경춘선과 무관한 별개 노선이다.** 2026-07-30 까지
  `'경춘'` 의 C25–C33(삼동~여주)으로 접혀 있었고 실제 정차역인 판교·성남·이매 3역은 빠져 있었다.
  그 상태에서는 삼동~여주가 **경로 탐색에서 완전히 도달 불가**였다 — 유일한 연결 시도였던
  이매(B19)↔삼동(C25) 수기 환승 connection 을 `GraphBuilder._addConnectionEdges` 가
  `isTransfer` 라 건너뛰고, 환승 edge 는 `_addTransferEdges` 가 **역명 일치**로만 만들기
  때문에(이매≠삼동) 어떤 edge 도 생성되지 않았다. 함께 정정한 것:
  - 판교(GG01↔D08 신분당)·성남(GG02↔G07 GTX-A)·이매(GG03↔B19 수인분당) 환승 신설.
    역명이 같아 환승 edge 는 자동 생성되므로 수기 connection 은 두지 않는다.
  - `subwayIdToLineId['1081']` 이 `'에버라인'` → `'경강'`. 실시간 API 실측 기준 1081 은
    경강선이며, 에버라인은 서울 실시간 API 미제공이다.
  - 방향: 앱 일반규칙(ID 증가 = 하행)이 API 라벨과 일치("여주행"=하행, "판교행"=상행).
  - 시간표는 `line_schedules.json` 의 독립 `'경강'` 엔트리(12역 전체, 급행 없음).
  - 회귀 가드: `test/data/gyeonggang_line_test.dart`.
- 수인분당선 K266(원인재)만 `B` 접두사를 쓰지 않는다(경의중앙 계열 ID 체계 잔존).
- **인천1호선 부평구청(I12)·부평(I14)은 2026-07-28에 추가된 역이다.** 그전까지 두 역이 빠진 채
  `갈산 → 부평시장`(270초)·`부평시장 → 동수`(120초)로 직결돼 있어, 1호선↔인천1 부평 환승과
  7호선↔인천1 부평구청 환승이 그래프에 존재하지 않았다(환승시간·환승안내 데이터는 이미 있었음).
  추가 시 구 `I12`~`I31` 을 `I13`~`I33` 으로 재번호했다 — 방향 판정이 "ID 증가 = 하행" 규칙에
  의존하므로 물리 순서와 ID 순서가 일치해야 한다.
  - 위치 근거: 인천교통공사 시각표 CSV 컬럼 순서(갈산-부평구청-부평시장-부평-동수)와
    `svg_station_coords.json` y좌표 단조성(872-944-992-1048-1120)이 독립적으로 일치.
  - 같은 작업에서 인천1 소요시간 32구간을 CSV 실측값으로 교체했다(18건 수정). 기존 값은
    `generate_station_data.dart` 의 좌표 거리 기반 추정(35km/h·60~300초 클램프)이라
    인천대입구→센트럴파크 300초(실제 90초) 같은 큰 오차가 있었다.
- 경춘선 C01–C05(청량리~망우)와 경의중앙선 K32–K36은 물리적으로 같은 선로이나 별개 노드 + 환승 엣지로 처리한다.
- 수인분당선 B43–B50(한대앞~오이도)과 4호선 441–448도 별개 노드 + 환승 엣지로 처리한다

## 지도 노선 배지 표기명

지도 위 노선 pill 배지(노선당 양 종점 2개, 총 48개)의 문구는 기본적으로 `lines.json`
의 `name` 이지만, **`tool/line_badges.dart` 의 `kLineBadgeNames` 에 항목이 있으면 그
값이 우선**한다. 현재 축약 항목은 하나다:

| lineId | lines.json `name` | 배지 표기 | 사유 |
|---|---|---|---|
| `김포골드` | 김포골드라인 | **김포골드** | 배치. 6글자 pill(84px)이 양촌 허브에 들어갈 틈이 없었다 |
| `우이신설` | 우이신설경전철 | **우이신설** | 가독성. 7자로 전 배지 최장이었고, 배지는 줌아웃 보정을 받지 않아 최대 줌아웃에서 6px 이 된다 |

⚠️ **`lines.json` 의 `name` 만 고치면 배지는 따라오지 않는다** — 축약 항목이 있는
노선은 `kLineBadgeNames` 도 함께 고쳐야 한다.

축약 시 제약(어기면 지도 빌드 실패):
- 실제 역명과 같을 수 없다 — 배지가 역명 라벨로 오독된다. 그래서 `의정부경전철`
  은 "의정부" 로 줄일 수 없다(의정부역 실존).
- 두 노선의 배지 문구가 같을 수 없다.
- 축약표 키는 `lines.json` 에 있는 lineId 여야 하고, 값은 비어 있을 수 없다.

⛔ **축약을 늘리는 것은 사용자 승인 사안이다.** 배치가 빡빡하다는 이유로 임의로
추가하지 말 것 — 한때 앵커 상한을 16px 로 두고 `2호선`→"2호", `수인분당선`→
"수인분당", `우이신설경전철`→"우이" 까지 줄였다가, **"2호" 는 다른 노선이 전부
"N호선" 인 가운데 혼자 표기가 깨지고 실제로 쓰이지 않는 이름**이라 철회했다.
앵커 상한을 24px 로 올리면 공식 명칭 그대로도 전 노선이 풀리고 겹침도 더 좋다.
