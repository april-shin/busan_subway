## 노선별 특이사항

- 신분당선은 `'SB'`와 `'신분당'` 두 가지 ID가 모두 색상/이름 맵에 등록되어 있다. `lines.json`에서는 `'SB'`를 사용한다.
- **5호선 마천 지선(550 둔촌동 ~ 556 마천)은 539(강동)에서 분기한다.** 역 목록이 하남 방면
  종점 549(하남검단산) 다음에 둔촌동을 나열하므로 `generate_station_data.dart` 의 자동 인접
  연결이 `549 → 550` 이라는 없는 연결을 만든다. 생성기의 `lineId == '5'` 블록이 이를 제거하고
  `539 → 550` 을 추가한다. 이 처리가 빠지면 5호선이 지선 없는 일직선이 되어 (1) 천호→마천이
  하남검단산을 돌아가는 19역 경로로 뽑히고 (2) 지도 실시간 열차의 지선 판정이 무력화돼
  `천호 → 굽은다리` 경로에 마천행이 표시된다. 회귀 가드: `test/data/line5_macheon_branch_test.dart`.
- 경의중앙선 K54(서울역)는 K24(효창공원앞)에서 분기하는 dead-end 지선이다. K55(임진강)·K56(운천)은
  K01(문산) 이북 연장 구간으로 하루 2~4편만 운행한다.
- 경춘선 C25–C33(삼동~여주)은 실제로는 경강선 구간이나 앱에서는 `'경춘'` 하나로 묶어 관리한다.
  시간표 수집 시 `경춘선`·`경강선` 두 노선명을 모두 조회하는 이유(`build_gettrainsch_timetable.dart`).
- 수인분당선 K266(원인재)만 `B` 접두사를 쓰지 않는다(경의중앙 계열 ID 체계 잔존).
- **인천1호선 부평구청(I12)·부평(I14)은 2026-07-28에 추가된 역이다.** 그전까지 두 역이 빠진 채
  `갈산 → 부평시장`(270초)·`부평시장 → 동수`(120초)로 직결돼 있어, 1호선↔인천1 부평 환승과
  7호선↔인천1 부평구청 환승이 그래프에 존재하지 않았다(환승시간·환승안내 데이터는 이미 있었음).
  추가 시 구 `I12`~`I31` 을 `I13`~`I33` 으로 재번호했다 — 방향 판정이 "ID 증가 = 하행" 규칙에
  의존하므로 물리 순서와 ID 순서가 일치해야 한다.
  - 위치 근거: 인천교통공사 시각표 CSV 컬럼 순서(갈산-부평구청-부평시장-부평-동수)와
    `svg_station_coords.json` y좌표 단조성(872-944-992-1048-1120)이 독립적으로 일치.
  - 같은 작업에서 인천1 소요시간 32구간을 CSV 실측값으로 교체했다(18건 수정). 기존 값은
    `generate_station_data.dart` 의 좌표 거리 기반 추정(35km/h·60~300초 클램프)이라
    인천대입구→센트럴파크 300초(실제 90초) 같은 큰 오차가 있었다.
- 경춘선 C01–C05(청량리~망우)와 경의중앙선 K32–K36은 물리적으로 같은 선로이나 별개 노드 + 환승 엣지로 처리한다.
- 수인분당선 B43–B50(한대앞~오이도)과 4호선 441–448도 별개 노드 + 환승 엣지로 처리한다
