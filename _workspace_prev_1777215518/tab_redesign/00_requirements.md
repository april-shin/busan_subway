# 요구사항 — 경로 결과 탭 동적 결정 + 토글 제거

## 사용자 원본 요청

> 언주>마곡나루를 가는 케이스를 생각해보면 완행>급행으로 갈아타는데 최단시간은 갈아타는 케이스, 최소환승은 완행만 타고 가는 케이스야 이러땐 '급행/완행' 탭이 없어야해. 신논현>마곡나루를 가는 케이스는 급행만 타고 가는 경우와 완행만 타고 가는 경우 두가지로 나뉘어져, 이럴때는 '급행/완행' 탭으로 두 케이스를 볼수있게 나누어져야해. 마지막으로 이 내용을 조회할때, 출발시간은 급행을 탈때는 급행출발시간, 완행을 탈땐 완행출발시간으로 다른 출발시간이 노출되어야해

## 핵심 요구사항

1. 두 후보 경로의 차이가 **환승 횟수**이면(언주→마곡나루) → "최단시간/최소환승" 탭. 모드 토글 없음.
2. 두 후보 경로의 차이가 **모드(급행/완행)**이면(신논현→마곡나루) → "급행/완행" 탭. 모드 토글 없음.
3. 단일 경로면 탭 없음.
4. 출발 시각: 각 탭의 모드에 맞춰 다르게 (급행 탭은 급행 도착정보, 완행 탭은 완행 도착정보).
5. `_TrainModeToggle`은 제거 (탭이 모드를 구분하므로 중복).
