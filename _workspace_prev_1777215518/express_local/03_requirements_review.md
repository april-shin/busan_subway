### ❌ 누락 (CRITICAL)

  - `assets/json/connections.json`의 expressTimeSeconds 분포: 1호선 92건, 수인분당 46건, 경춘 22건, **9호선 단 1건**

  - 알고리즘 한계: `compute_travel_times.dart`는 **인접 두 역**의 시간표만 매칭 (`assets/json/connections.json` 기준 인접한 fromStationId, toStationId). 9호선 급행은 일부 역만 정차하므로 인접 두 역(예: 김포공항 902 → 공항시장 903) 양쪽에 같은 trainno가 동시에 등장하지 않음 → 매칭 0건.

### ⚠ 부분 구현

#### 1. 급행 시간 합산 로직의 잠복 버그 (코드 리뷰 CRITICAL 1번)

- 한 세그먼트 내에서 첫 N개 edge가 급행 미운영, 그 뒤가 운영인 경우 앞쪽 N개 edge의 weightSeconds가 expressDurationSeconds에 누락됨.
- plan의 사용자 결정사항 #3 "급행 미정차역 출발/도착이면 가까운 급행역까지는 완행 시간, 그 이후는 급행 시간으로 혼합 적용" 의도와 정면 위배.
- 사용자 시나리오: 출발역이 급행 미정차역인 경우 (예: 김포공항이 급행 정차역이지만, 만약 출발이 양천향교라면) → 양천향교→마곡나루(완행) 시간이 통째로 누락되어 급행 시간이 비현실적으로 짧게 표시.
- 코드 리뷰 CRITICAL과 동일 사안이므로 함께 수정 필요. 테스트도 추가.

## 엣지 케이스

### ⚠ 처리되지 않은 케이스

1. **출발역이 급행 미정차역** (코드 리뷰 CRITICAL과 연계)
   - 예: 양천향교(906) 출발 → 김포공항(902) 도착. 양천향교는 9호선 급행 미정차.
   - 현재 로직: 양천향교→가양 등 완행 구간 전부 누락하고 가양 이후만 급행으로 계산.

2. **도착역이 급행 미정차역**
   - 활성화 후 폴백은 작동하므로 부분적으로 처리됨. 단, 마지막 edge가 급행 미운영이면 완행 weight로 fallback (정상). 다만 사용자가 인지할 수 있게 UI에서 "도착역은 급행 미정차" 표기 권장.

3. **2호선 순환선** — 본 PR 영향 없음 (2호선 급행 데이터 자체가 없으므로 비활성). 정상.

4. **4호선 진접선 분기** — 본 PR 영향 없음. 정상.

5. **노선 ID 변경/병합 (예: 수인분당 데이터 갱신 시 stale)** — `compute_travel_times.dart:147`의 `c.remove('expressTimeSeconds')`가 일시 시간표 누락 시 기존 값을 날려버릴 수 있음 (코드 리뷰 MEDIUM 6).

6. **오프라인 상태** — 본 PR은 데이터 + UI 토글만 다룸. 오프라인 시에도 connections.json은 번들에서 로드되므로 정상 작동. 도착시각은 캐시 폴백 동작. 정상.

7. **API 응답 지연 시 토글 동작** — `effectiveMode = _isExpressAvailable ? _trainMode : TrainMode.local` 폴백이 잘 적용됨. ✅

8. **역 이름 중복 (다른 노선의 동일 역명)** — `compute_travel_times.dart`는 `(lineId, name)` 페어로 매칭하므로 충돌 없음. ✅

## 오버 엔지니어링

### ⚠ 검토 항목

1. **GraphEdge.expressWeightSeconds** — 현재 Dijkstra 가중치엔 사용 안 함. plan 사용자 결정사항 #1을 충실히 따른 결과로, "추후 급행 가중 Dijkstra로 별도 경로 탐색을 위한 확장점"으로 의도가 명시적. **오버 엔지니어링 아님** — 지금은 필요한 데이터 전달 통로로만 사용.

2. **`_TrainModeToggle` 위젯 분리** — 한 화면에서만 쓰지만, 위젯 단위로 잘 추출되어 가독성 좋음. **오버 엔지니어링 아님**.

3. **`enum TrainMode { local, express }`** — bool 하나로도 가능하지만 enum이 명시적이고 확장성(쾌속/특급 등 미래 추가) 면에서 적절. **오버 엔지니어링 아님**.
